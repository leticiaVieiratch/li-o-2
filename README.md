# pausa ☕

Um guia de cafeterias especiais em São Paulo, feito para encontrar um lugar gostoso para respirar, tomar um café e desacelerar.

## O que dá para fazer

- Buscar cafeterias por nome, bairro ou descrição.
- Filtrar lugares para trabalhar, ao ar livre ou pet friendly.
- Salvar cafés favoritos para ver depois.
- Sortear um lugar para a próxima pausa.
- Usar o site no celular, tablet ou computador.

## Rodar localmente

Você precisa ter o [Node.js](https://nodejs.org/) instalado. Na primeira vez, instale as dependências:

```bash
npm install
```

Inicie o servidor de desenvolvimento:

```bash
npm run dev
```

Abra no navegador o endereço mostrado no terminal — normalmente <http://localhost:5173/>.

## Comandos

| Comando | O que faz |
| --- | --- |
| `npm run dev` | Inicia o servidor local com atualização automática |
| `npm run build` | Verifica os tipos e gera a versão de produção em `dist/` |
| `npm run preview` | Abre localmente uma prévia da versão de produção |
| `npm run lint` | Analisa o código com Oxlint |

## Tecnologias

- React
- TypeScript
- Vite
- Oxlint

As fotografias e fontes são carregadas de serviços externos e precisam de conexão com a internet para aparecer corretamente.
